# Emotion Sentiment Analysis

This project focuses on classifying emotions from social media text using machine learning and deep learning models.

## Objectives
- Classify posts into emotions like joy, anger, sadness, etc.
- Build and evaluate models including Logistic Regression, Random Forest, and LSTM.
- Visualize insights and results.
- (Optional) Deploy the model using Streamlit.

## Dataset
- Twitter API data and Kaggle Emotion Dataset (~40,000 samples)
